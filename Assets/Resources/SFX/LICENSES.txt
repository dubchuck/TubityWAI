All files were loudness-normalized (~-16 LUFS) and converted to 16-bit/44.1kHz WAV
for consistency. To swap any sound, replace the file in this folder keeping the
same filename — ProceduralAudio.cs loads clips by name via Resources.Load and
falls back to its built-in synthesized tone if a file is missing.
